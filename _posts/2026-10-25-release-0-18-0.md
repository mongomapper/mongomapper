MongoMapper 0.18.0 has been released.

This release adds GlobalID support, MongoMapper.setup_with_config_file, a YAML alias/psych config fix, a static_keys embedded-doc fix, and support for Ruby 4.0, Rails 8.1, and MongoDB 8.0.

Thanks to the many contributors!

See the [changelog](https://github.com/mongomapper/mongomapper/blob/master/CHANGELOG.md#0180---2026-10-25) for full details.
